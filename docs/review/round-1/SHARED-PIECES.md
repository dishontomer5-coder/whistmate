# Shared pieces (from the foundation implementer — already on main). Use these; do not re-create them.

- **`@/components/ConfirmDialog`** — `ConfirmDialog({ open, onOpenChange, title, description, confirmLabel='Confirm', cancelLabel='Cancel', destructive, busy, confirmDisabled, onConfirm, children })`. `onConfirm` does not close it: set `open` false yourself. `confirmDisabled` is for a type-the-name step. `useConfirm()` → `[confirm, confirmElement]`; `await confirm({ title, description, confirmLabel, cancelLabel, destructive })` → true/false; render `confirmElement` once. `title`/`description` take JSX. Never `window.confirm`, never in-place Confirm/Cancel button swaps.
- **`@/components/UserText`** — `Name` (`<bdi>`, for any user-given name, in a sentence or alone; keep a row number outside it: `{i + 1}. <Name>…</Name>`), `UserText({ as='span' })` (`dir="auto"`; as a block it also right-aligns Hebrew — add `text-start` if an ancestor sets `text-left`), `dirAuto` (`<Input {...dirAuto} />` on every field a user types names or free text into).
- **`@/lib/format`** — `scoreTone(n)` (gold / muted / red-text class for a gained / zero / lost score), `formatScore`, `formatPct`, `formatDate`, `parseDate`, `todayLocalISO`, `defaultSessionName(date)` ("Thursday, 19 Nov"), `sessionName(session)`, `errorMessage(err, fallback)` (the server's words first; a network failure becomes `OFFLINE_MESSAGE`).
- **`@/components/TableBadge`** (default export) — `{ state: 'up'|'down', total?, onClick?, className? }`; with `onClick` it is a button with a 44 px tap area.
- **`@/components/Suit`** — `Suit({ suit, label?, className? })`, `SUIT_LABEL` (words), `SUIT_GLYPH`, `SUITS_IN_AUCTION_ORDER`, `isRedSuit`, `SuitText` (colours ♥ ♦ inside free text). Do not put a `Suit` on a gold fill; show selection with an outline.
- **`@/components/PlayerAvatar`** (default) — `{ name, size: 'sm'|'md'|'lg' }` (32/36/56 px).
- **`@/components/EmptyState`** (default) — `{ icon: LucideComponent = Spade, title, description?, action?, compact?, as='h2' }`.
- **`@/components/ErrorState`** (default) — block: `{ title?, message, onRetry?, retryLabel='Try again', action? }`; one line: `<ErrorState inline message={error} />` (renders nothing when empty). Put the inline form directly under the field or beside the button that caused it.
- **`@/components/ScoringHelp`** — `ScoringHelp({ open, onOpenChange, section? })`, `ScoringHelpButton({ section?, label?, className? })` (a 44×44 "?", self-contained). Sections: `contract | miss | zero | updown | everyone-falls | renege | trump`.
- **`@/lib/scoring-help`** — `SCORING_HELP`, `SCORING_METHOD_SUMMARY`, `SCORING_METHOD_LABEL`, `CARD_ORDER_LABEL` ("Ace high" / "Ace high, then 2 up to King"), `CARD_ORDER_DETAIL`, `PROGRESSIVE_TIERS`, `CLASSIC_RATE`, `MADE_BONUS`, `signed`.
- **Primitives** — `Button` sizes: default 44 px, `lg` 52 px (the ONE primary action of a screen), `sm` 36 px drawn with a 44 px tap area (inline uses only), `icon` 44×44. Do not pass `h-*` or `border-*` to `Button` / `Input` / `Textarea` / `SelectTrigger`. `DialogContent position="sheet"` gives a bottom sheet on phones.
- **CSS / Tailwind** — `text-negative` for red TEXT; `destructive` for fills and borders only. Classes `.page-title`, `.section-title`, `.section-label`. Nothing below `text-xs` (12 px). Button labels, titles and form labels are sentence case ("Save round", "Create group").
